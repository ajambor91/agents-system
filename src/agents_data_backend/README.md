# agent-data-backend

Backend danych agentów. Docelowo przejmie z `communication_stack` zapis do
MongoDB, cache Redis oraz kontrakty repozytoriów danych. Katalog jest obecnie
szkieletem i celowo nie łączy się jeszcze z MongoDB ani Redisem.

Plan migracji znajduje się w
[COMMUNICATION_STACK_MERGE.md](../../COMMUNICATION_STACK_MERGE.md).
